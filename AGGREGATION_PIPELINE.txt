==================================================
PIPELINE OVERVIEW
=================

Purpose:
Pre-compute analytics metrics daily to reduce dashboard query time and improve reporting performance.

Aggregation Schedule:

* Daily
* Execution Time: 11:59 PM
* Expected Runtime: Less than 5 minutes

==================================================
DATA SOURCES
============

Source Tables:

* decisions
* applications
* audit_trail

Input Data:

* Decision outcomes
* Analyst actions
* Processing timestamps
* Rule evaluation results

==================================================
METRICS CALCULATED
==================

1. Approval Rate

---

Calculation:
Approved Applications / Total Applications

Frequency:
Daily

==================================================

2. Rejection Rate

---

Calculation:
Rejected Applications / Total Applications

Frequency:
Daily

==================================================

3. Average Decision Latency

---

Calculation:
Average processing time per decision

Frequency:
Daily

==================================================

4. Rule Effectiveness

---

Calculation:
Percentage of rule triggers resulting in correct decisions

Frequency:
Daily

==================================================
AGGREGATION PROCESS
===================

Step 1:
Collect decision data from previous day

Step 2:
Calculate approval and rejection metrics

Step 3:
Calculate average decision latency

Step 4:
Calculate rule effectiveness metrics

Step 5:
Store results in aggregation table
